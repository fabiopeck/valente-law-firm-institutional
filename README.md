# Valente & Associados | Advocacia Empresarial

Site institucional de advocacia empresarial, em português, feito como **projeto de portfólio**. Serve para empresas avaliarem layout, organização das páginas, conteúdo e navegação.

Não é o site de um escritório real. Os dados (equipe, telefone, e-mail e clientes) são demonstrativos.

## O que o projeto mostra

* Home com identidade visual, áreas de atuação, equipe e contato
* Páginas internas: Sobre, Áreas de Atuação, Equipe, Consulta e Contato
* Menu em português, rodapé, WhatsApp e mapa de Belo Horizonte
* Barra de cookies na home
* Layout responsivo para desktop e celular

## Páginas

* Início: `index.html`
* Sobre: `sobre.html`
* Áreas de Atuação: `areas.html`
* Equipe: `equipe.html`
* Consulta: `consulta.html`
* Contato: `contato.html`

## Como visualizar

Na pasta do projeto:

```bash
python3 -m http.server 8000
```

Abra [http://localhost:8000](http://localhost:8000).

## Tecnologias

* HTML5, CSS3 e JavaScript
* Site estático (sem banco de dados e sem backend)
* Tipografia Montserrat e Lato

## Direitos

Todos os direitos reservados. Visualização de portfólio. Textos, fotos e identidade visual não devem ser reutilizados sem autorização.
